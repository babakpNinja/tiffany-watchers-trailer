# Who Watches the Watchers

A 60 second claymation trailer for Tiffany Li (The Information, AI-safety beat).

Built by NinjaTech. Creative trailer, not a news report: the labs are generic
clay towers, no real logos or executive likenesses. No pricing anywhere.

- `assets/trailer.mp4` — the finished 60s film (1280x720, 24fps).
- `index.html` — the watch page, in The Information's design system (Suisse
  fonts, brand red, real wordmark).

Source of the creative: `SCRIPT.md` in the build workspace.
Run locally: `python -m http.server 8080` and open the page.
